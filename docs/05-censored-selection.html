5  Censored Regression and Sample Selection

5.1 Tobit model

Many outcomes are zero for a part of the population and continuous and positive for the rest, for example expenditures or hours worked. The Tobit model (Tobin 1958) writes \[ y^* = x\beta + u, \quad u \mid x \sim N(0, \sigma^2), \qquad y = \max(0, y^*). \] It is estimated by maximum likelihood. The coefficients \(\beta\) are the effects on the latent \(y^*\). The partial effect on the observed outcome is \[ \frac{\partial E(y \mid x)}{\partial x_j} = \beta_j \, \Phi(x\beta/\sigma), \] which is smaller in absolute value than \(\beta_j\).

5.1.1 Example: Fringe benefits

The data set fringe contains 616 workers (Wooldridge 2020). The outcome hrbens is hourly fringe benefits in dollars; 6.7 percent of the workers have none.

We use censReg() from the package of the same name. In its output, logSigma is \(\log\sigma\).

data(fringe, package = "wooldridge")
library(censReg)
tobit <- censReg(hrbens ~ exper + age + educ + tenure + married + male + white +
                   nrtheast + nrthcen + south + union, data = fringe)
summary(tobit)

library(survival)
tobitx <- survreg(Surv(hrbens, hrbens > 0, type = "left") ~ exper + age + educ + tenure +
                    married + male + white + nrtheast + nrthcen + south + union,
                  data = fringe, dist = "gaussian")

5.2 Heckman selection model

In the selection model (Heckman 1979), the outcome is observed only for a selected part of the sample: \[ \begin{aligned} d &= 1[z\gamma + v > 0] && \text{(selection equation)}\\ y &= x\beta + u, \ \text{ observed only if } d = 1 && \text{(outcome equation)} \end{aligned} \] with \((u, v)\) jointly normal and \(\text{Corr}(u, v) = \rho\). If \(\rho \ne 0\), OLS on the selected sample is inconsistent, because \[ E(y \mid x, d = 1) = x\beta + \rho\sigma_u \, \lambda(z\gamma), \] where \(\lambda(\cdot) = \phi(\cdot)/\Phi(\cdot)\) is the inverse Mills ratio. The two-step estimator first estimates \(\gamma\) by probit, then regresses \(y\) on \(x\) and \(\lambda(z\hat\gamma)\) by OLS in the selected sample. The coefficient on \(\lambda\) estimates \(\rho\sigma_u\); its \(t\) test is a test of selection bias.

5.2.1 Example: Ambulatory expenditures

We use the data on ambulatory medical expenditures (ambexp) from Cameron and Trivedi (2010). Expenditures are observed for those with positive spending; the outcome equation is for log expenditures. Save mus16data.dta in your working directory first.

library(haven)
mus16data <- read_dta("mus16data.dta")

mus16data$dy  <- as.numeric(mus16data$ambexp > 0)       # selection indicator
mus16data$lny <- ifelse(mus16data$ambexp > 0, log(mus16data$ambexp), NA)
table(mus16data$dy)
#> 
#>    0    1 
#>  526 2802

Regressors are age, gender, years of education, a dummy for Black or Hispanic (blhisp) and the number of chronic diseases (totchr). We estimate the model with selection() from the package sampleSelection.

library(sampleSelection)
heckman <- selection(dy  ~ age + female + educ + blhisp + totchr,
                     lny ~ age + female + educ + blhisp + totchr,
                     data = mus16data, method = "2step")
summary(heckman)

The coefficient on the inverse Mills ratio (invMillsRatio) is -0.44 and not significant at conventional levels, so these data show no clear evidence of selection bias.

Note that both equations here contain the same regressors. The model is then identified only through the nonlinearity of \(\lambda(\cdot)\), which often makes the two-step estimates imprecise. In applications one should have at least one variable in the selection equation that is excluded from the outcome equation. With method = "ml", selection() estimates the model by maximum likelihood instead.
